# Decisiones iniciales

- Será un programa de escritorio para Windows.
- La primera versión funcionará en una sola computadora.
- El backend y PostgreSQL se ejecutarán localmente.
- Se probará con datos falsos y se limpiará la base antes de usar datos reales.
- Los productos podrán venderse por unidad, paquete, caja, peso o volumen.
- Las cantidades de inventario admitirán decimales.
- Cada producto podrá usar precio único o precios por franjas horarias.
- Las franjas y sus horarios se configurarán posteriormente.
- Un precio especial de cliente y producto tendrá prioridad sobre los demás.
- No habrá precio de mayoreo según cantidad.
- No se implementará facturación fiscal.
- La impresora generará únicamente recibos internos.
- Las ventas y movimientos sensibles no se eliminarán: se anularán o reversarán.
